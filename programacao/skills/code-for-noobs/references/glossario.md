# Glossário para principiantes

Definições curtas e analogias para os termos que mais aparecem. Usa a definição como ponto de partida e adapta ao contexto — não copies a lista inteira para a resposta, só os termos que a pessoa precisa.

## Básicos de programação

| Termo | Em uma frase | Analogia |
|---|---|---|
| **Código** | Instruções escritas para o computador seguir, passo a passo. | Uma receita: o computador é o cozinheiro que faz exatamente o que lá está, nem mais nem menos. |
| **Linguagem de programação** | A "língua" em que se escreve o código (ex.: Python, Swift, JavaScript). | Línguas diferentes para dizer a mesma receita: português, inglês, francês. |
| **Variável** | Um nome que guarda um valor para usar mais tarde. | Uma caixa com uma etiqueta: "idade" tem lá dentro 30. |
| **Valor** | O dado em si: um número, um texto, verdadeiro/falso. | O que está dentro da caixa. |
| **Tipo** | O género de valor (número, texto, sim/não). | Não se põe sopa numa caixa de sapatos — cada caixa serve para uma coisa. |
| **Função** | Um conjunto de passos com nome, que podes repetir quando quiseres. | Uma receita: "fazer bolo" — chamas a receita e ela faz os passos todos. |
| **Parâmetro** | A informação que dás a uma função para ela trabalhar. | Os ingredientes que entregas à receita. |
| **If (se)** | Faz uma coisa só quando uma condição é verdadeira. | "Se estiver a chover, leva guarda-chuva." |
| **Ciclo (loop)** | Repete passos várias vezes. | "Para cada prato no lava-loiça, lava-o." |
| **Lista (array)** | Vários valores guardados por ordem. | Uma lista de compras numerada. |
| **Objeto** | Um conjunto de informações sobre uma coisa, cada uma com um nome. | Uma ficha de contacto: nome, telefone, email. |
| **Comentário** | Texto no código que o computador ignora; serve para pessoas. | Post-its colados na receita. |
| **Bug** | Um erro no programa que o faz comportar-se mal. | Um passo errado na receita: o bolo sai salgado. |

## Onde o código vive

| Termo | Em uma frase | Analogia |
|---|---|---|
| **Ficheiro** | Um documento com código ou dados. | Uma página de um livro de receitas. |
| **Projeto / pasta** | Todos os ficheiros de uma app juntos. | O livro de receitas inteiro. |
| **Editor / IDE** | O programa onde escreves código (ex.: VS Code, Xcode). | O processador de texto, mas para código. |
| **Terminal** | Uma janela onde dás ordens ao computador por escrito. | Falar com o computador por mensagens em vez de cliques. |
| **Compilar / build** | Transformar o código numa app que o computador ou telemóvel consegue correr. | Cozinhar a receita: o código é a receita, a app é o prato. |
| **Correr (run)** | Pôr o programa a funcionar. | Ligar o aparelho. |

## Internet e apps

| Termo | Em uma frase | Analogia |
|---|---|---|
| **Servidor** | Um computador sempre ligado que responde a pedidos de outras máquinas. | A cozinha de um restaurante, sempre a funcionar. |
| **Cliente** | O programa que faz pedidos ao servidor (a app, o browser). | O cliente do restaurante. |
| **Frontend** | A parte da app que vês e tocas. | A sala do restaurante: mesas, menu, decoração. |
| **Backend** | A parte que trabalha nos bastidores (servidor, dados). | A cozinha. |
| **API** | A forma combinada de um programa pedir coisas a outro. | O empregado de mesa entre ti e a cozinha. |
| **Base de dados** | Onde a app guarda informação de forma organizada. | Um arquivo com gavetas e fichas bem arrumadas. |
| **JSON** | Um formato de texto para trocar dados entre programas. | Um formulário com campos e respostas: `"nome": "Ana"`. |
| **URL** | O endereço de algo na internet. | A morada de uma casa. |
| **Deploy / publicar** | Pôr uma versão nova da app disponível para as pessoas. | Abrir as portas do restaurante com o menu novo. |

## Ferramentas

| Termo | Em uma frase | Analogia |
|---|---|---|
| **Biblioteca / pacote** | Código feito por outras pessoas que podes usar no teu. | Comprar massa folhada feita em vez de a fazer de raiz. |
| **Framework** | Uma estrutura pronta onde encaixas o teu código. | Uma casa pré-fabricada: tu decides a decoração e as divisões. |
| **Git** | Uma ferramenta que guarda o histórico de todas as versões do teu código. | Um "guardar como" infinito, com data e nota em cada versão. |
| **Commit** | Uma fotografia do projeto num momento, com uma nota a explicar o que mudou. | Uma página de diário: "hoje mudei o botão para azul". |
| **Branch** | Uma cópia paralela do projeto para experimentar sem estragar o principal. | Fotocopiar a receita para testar uma variação. |
| **Push / pull** | Enviar as tuas versões para a internet / trazer as dos outros. | Enviar e receber correio. |
| **Repositório (repo)** | A pasta do projeto com todo o seu histórico, muitas vezes guardada online (ex.: GitHub). | A biblioteca onde fica o livro de receitas e todas as edições antigas. |
| **Pull request** | Um pedido para juntar as tuas alterações ao projeto principal, para alguém rever. | Entregar um trabalho ao professor antes de ir para a pauta. |

## Erros

| Termo | Em uma frase | Analogia |
|---|---|---|
| **Erro de sintaxe** | O código está mal escrito e o computador não o percebe. | Uma frase com gralhas que ninguém consegue ler. |
| **Erro em execução** | O código está bem escrito, mas algo corre mal enquanto funciona. | A receita está certa, mas falta um ingrediente no armário. |
| **Null / nil** | "Nada" — uma variável que ainda não tem valor. | Uma caixa vazia: se tentares tirar algo de lá, não há. |
| **Stack trace** | A lista de passos que o programa estava a fazer quando deu erro. | O rasto de migalhas até ao sítio onde caíste. |
| **Debug** | Procurar e corrigir o que está a causar um bug. | Trabalho de detetive para descobrir porque o bolo saiu salgado. |
