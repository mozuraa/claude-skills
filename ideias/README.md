# 💡 Ideias

Skills que geram **poucas ideias, mas bem pensadas** — 2 a 3, cada uma com o mesmo formato detalhado, e no fim a recomendação de qual escolher.
*Skills that generate a few well-thought-out ideas — 2–3, each in the same detailed format, with a recommendation at the end.*

| Skill | O que faz · What it does | Repositório |
|---|---|---|
| [`ideias-funcionalidades`](skills/ideias-funcionalidades/SKILL.md) | Funcionalidades para uma app que **já existe**, verificadas no código · Features for an existing app | [claude-skill-ideias-funcionalidades](https://github.com/mozuraa/claude-skill-ideias-funcionalidades) |
| [`ideias-monetizacao`](skills/ideias-monetizacao/SKILL.md) | Formas justas de ganhar dinheiro, com preços concretos · Fair monetization with real prices | [claude-skill-ideias-monetizacao](https://github.com/mozuraa/claude-skill-ideias-monetizacao) |
| [`brainstorming`](skills/brainstorming/SKILL.md) | Ideias sobre **qualquer tema** · Ideas on any topic | [claude-skill-brainstorming](https://github.com/mozuraa/claude-skill-brainstorming) |

Para ideias de **apps e jogos novos** ou de **websites**, usa o modo 💡 Idear dos [Estúdios](../estudios/).
*For new app/game or website ideas, use the Ideate mode of the [Studios](../estudios/).*

**Instalar esta categoria · Install this category** (Claude Code):

```
/plugin marketplace add mozuraa/claude-skills
/plugin install ideias@mozuraa-skills
```
